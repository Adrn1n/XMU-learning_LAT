# 一、实验报告：数据构建与规范化词典
## 报告一：基于噪声注入合成与词典匹配的中文非规范词恢复方法
### 1. 实验目标
本实验的目标是设计并实现一个中文非规范词恢复程序，用于将微信、微博、小红书等社交媒体文本中的非规范表达恢复为规范表达。

社交媒体文本中常见的不规范现象包括：
| 类型 | 示例 | 规范形式 |
|---|---|---|
| 同音替换 | 蜀黍 | 叔叔 |
| 谐音替换 | 肿么 | 怎么 |
| 拼音缩写 | lz | 楼主 |
| 拼音混写 | bi zhan | B站 |
| 拆字 | 女兆日月 | 姚明 |
| 错别字 | 来去勿勿 | 来去匆匆 |
| 间隔符干扰 | 日-本-人 | 日本人 |
| 星号干扰 | 日*本*人 | 日本人 |

我负责的部分主要是：
1. 构建非规范词到规范词的映射词典；
2. 设计噪声注入方法，自动生成训练/测试数据；
3. 实现基于词典匹配的规范化 Baseline 系统；
4. 为后续模型训练和系统融合提供数据支持。

---

### 2. 实验设计思想
由于中文社交媒体中的非规范表达数量庞大、变化快，完全依靠人工标注成本较高。因此本部分采用：

> **噪声注入合成 + 人工词典 + 最大匹配替换**

的技术路线。

整体流程如下：

```text
规范语料
   ↓
噪声注入
   ↓
生成 非规范文本-规范文本 平行数据
   ↓
构建 mapping.json 规范化词典
   ↓
词典最大匹配替换
   ↓
输出规范化文本
```

这种方法的优点是：
1. 实现简单，容易调试；
2. 速度快，适合作为 Baseline；
3. 可解释性强，每一次替换都可以追踪来源；
4. 不依赖大规模人工标注；
5. 后续可以和规则模块、机器学习模块融合。

在规范词资源方面，除了人工构建网络用语词典外，还可以参考国家语言文字规范中的异形词整理资料，例如《第一批异形词整理表》对常用异形词给出了推荐词形，可作为规范词来源之一。该规范整理了普通话书面语中常见的 338 组异形词，并给出了推荐使用词形[[1](https://zh.wikisource.org/wiki/%E7%AC%AC%E4%B8%80%E6%89%B9%E5%BC%82%E5%BD%A2%E8%AF%8D%E6%95%B4%E7%90%86%E8%A1%A8)]。

### 3. 数据构建方法
#### 3.1 人工词典构建
首先人工收集常见的不规范词及其规范形式，构建 `mapping.json`。

例如：
```json
{
  "蜀黍": "叔叔",
  "肿么": "怎么",
  "神马": "什么",
  "酱紫": "这样子",
  "表酱紫": "不要这样子",
  "偶": "我",
  "泥": "你",
  "灰常": "非常",
  "稀饭": "喜欢",
  "次奥": "操",
  "lz": "楼主",
  "tmd": "他妈的",
  "nb": "牛逼",
  "bi zhan": "B站",
  "b zhan": "B站",
  "gwi则": "规则",
  "女兆日月": "姚明",
  "禾斗匕匕": "科比",
  "来去勿勿": "来去匆匆"
}
```

词典以 JSON 格式保存，便于后续维护和扩充。

---

#### 3.2 噪声注入合成数据
为了构造更多测试数据，我实现了一个噪声注入程序。

输入规范句子：

```text
我今天非常喜欢这个视频。
```

可以自动生成：

```text
偶今天灰常稀饭这个视频。
```

主要噪声类型包括：

##### 1. 同音/谐音替换
将常见词替换为网络谐音词，例如：
```text
叔叔 → 蜀黍
怎么 → 肿么
什么 → 神马
非常 → 灰常
喜欢 → 稀饭
```

##### 2. 拼音缩写替换
将部分词替换为拼音首字母：

```text
楼主 → lz
他妈的 → tmd
牛逼 → nb
```

##### 3. 拼音混写
将部分词替换为拼音或拼音混合形式：

```text
B站 → bi zhan
规则 → gwi则
```

##### 4. 间隔符干扰
在汉字之间插入 `-`、`·`、`*`、`/` 等符号：

```text
日本人 → 日-本-人
*** → 总·书·记
```

---

### 4. 规范化算法
本部分采用**最长优先匹配**策略。

如果词典中同时存在：
```text
表 → 不要
表酱紫 → 不要这样子
```

那么处理：
```text
表酱紫
```

时应优先匹配更长的词：
```text
表酱紫 → 不要这样子
```

而不是先把 `表` 替换成 `不要`。

因此，在加载词典后，对所有 key 按长度从大到小排序。

算法如下：
```python
keys = sorted(mapping.keys(), key=len, reverse=True)

for key in keys:
    text = text.replace(key, mapping[key])
```

### 5. 实验结果
在手工构造的测试样例上，词典匹配方法能够正确恢复大部分常见网络非规范表达。

#### 测试样例 1
输入：
```text
蜀黍你肿么还不来，偶灰常稀饭这个bi zhan视频
```

输出：
```text
叔叔你怎么还不来，我非常喜欢这个B站视频
```

#### 测试样例 2
输入：
```text
lz觉得这个人nb，表酱紫说话
```

输出：
```text
楼主觉得这个人牛逼，不要这样子说话
```

#### 测试样例 3
输入：
```text
女兆日月和禾斗匕匕都是篮球明星
```

输出：
```text
姚明和科比都是篮球明星
```

---

### 6. 遇到的问题与解决方法
#### 问题一：短词优先替换导致错误
例如词典中既有：
```text
表 → 不要
表酱紫 → 不要这样子
```

如果先替换 `表`，会导致 `表酱紫` 无法整体识别。

解决方法：
> 对词典 key 按长度降序排序，优先匹配长词。

---

#### 问题二：不规范词中可能插入空格或符号
例如：
```text
bi zhan
b-zhan
日-本-人
```

解决方法：
1. 对英文和拼音类表达进行大小写归一化；
2. 使用规则去除汉字之间的干扰符号；
3. 在词典中补充多种变体。

---

#### 问题三：词典覆盖率有限
网络用语更新速度很快，人工词典无法覆盖所有情况。

解决方法：
1. 用噪声注入方式自动构造数据；
2. 后续结合拼音模型或 Seq2Seq 模型；
3. 保留未命中的原文，避免过度修改。

---

### 7. 本部分工作总结
我负责完成了非规范词恢复系统中的数据与词典部分，主要工作包括：
1. 构建常见非规范词到规范词的映射词典；
2. 实现噪声注入程序，自动生成非规范文本；
3. 实现基于词典最大匹配的规范化程序；
4. 支持单句模式和文件批处理模式；
5. 为后续模型训练和系统整合提供数据基础。

本方法虽然不如深度学习模型灵活，但实现简单、运行速度快、可解释性强，非常适合作为整个系统的基础模块。
